# Competitor UIs for multi-session coding-agent control surfaces

Research date: 2026-09-07. All fetches were made on that date unless a page carries its own date, which is recorded.
Legend: **[V]** = read on the vendor's own site, docs, repo or blog (verified). **[S]** = second-hand (third-party article, search snippet, mirror, or inferred). **[B]** = the vendor's page blocked or failed; nothing was invented to fill the gap.

Wanigan's premise for comparison: local-first Electron; the operator is the constraint; nothing happens you can't see afterward; survives a quit; local and yours; say the true thing.

### Conductor (conductor.build)
- Sources: conductor.build (home, /pricing, /docs/, /docs/concepts/workflow, /docs/reference/diff-viewer, /docs/concepts/parallel-agents, /changelog, /changelog/0.35.0-workspace-status, /changelog/0.44.0-…, /changelog/0.52.0-sounds-colors, /blog) all fetched 2026-09-07 **[V]**; performance.dev/the-conductor-rewrite (undated third-party) **[S]**.
- Positioning **[V]**: "Run parallel Claude Code, Codex, and Cursor agents in isolated workspaces", "Run parallel coding agents on your Mac". Docs add OpenCode. Latest version on the home page: 0.84.2.
- Layout **[V]**: workspace sidebar; "The workspace is the unit of delegation. The branch and pull request are the unit of integration." Shortcuts: ⌘⇧N new workspace, ⌘⇧D diff, ⌘⇧P create PR. "Archive finished workspaces so your sidebar stays focused"; restore from the History pane.
- State **[V]**: 0.35.0 (Feb 11 2026): "Workspaces are now organized by status: backlog, in progress, in review, and done." 0.44.0 (Mar 24 2026): "New, simplified sidebar" showing "GitHub status (merged, failing CI, conflicts, etc at a glance)"; Codex checkpoints "reset to a previous turn".
- Attention **[V]**: 0.52.0 (May 7 2026) added completion sounds ("SNCF jingle, a Paris Métro chime, and a Paris Métro pickpocket announcement"). No page read documents a per-workspace "needs you" indicator; treat as unknown, not absent.
- Diff/PR **[V]**: file list navigation; "Use unified diff when you want the old and new code in one column"; comments "point at changed lines, so the agent gets more precise context"; GitHub review comments shown with resolve; Checks tab covers "git status, CI, deployments, comments, and todos".
- Typography/colour **[V]**: custom fonts since 0.9.0 (Sep 1 2025), more fonts 0.27.0 (Dec 18 2025); nine syntax themes (Catppuccin, Dracula, Nord, Tokyo Night, Gruvbox, Solarized…) and "colorblind-friendly, accessible color options" in Settings > Appearance (May 7 2026). "0.6.0: A New Look" (Aug 9 2025) was a visual redesign; content not read.
- Pricing **[V]**: Free $0 (parallel agents, local workspaces on your Mac); Pro $50/mo (Conductor Cloud on Vercel sandboxes, 8-core/16 GB, us-east-1; multiplayer up to 5; API; mobile app "coming very soon"); Teams $60/mo/user (invite-only); Enterprise custom.
- Technology **[S]**: performance.dev says the rewrite moved to Tauri over Electron with a Rust core spawning agent CLIs, native WebKit webview, local-first SQLite, TanStack Router, react-virtuoso, Node→Bun. Conductor's own changelog and blog index do not mention Tauri; unverified.
- Design writing **[V]**: blog has only three posts (Claude subscription update Jun 15 2026; "cmd joins Conductor" Apr 2 2026; Series A Mar 30 2026); no design essay.

### Claude Code Desktop (Code tab) and Cowork
- Sources: code.claude.com/docs/en/desktop and /desktop-quickstart **[V]**; claude.com/product/cowork **[V]**; dbreunig.com 2026-02-21 "Why is Claude an Electron App?" **[S]**.
- Layout **[V]**: Desktop has three tabs, Chat / Cowork / Code. "The sidebar lists your sessions and lets you run several in parallel." Panes: "chat, diff, browser, terminal, file, plan, tasks, and subagent, along with the iOS Simulator on macOS. Drag a pane by its header to reposition it." ⌘\ closes a pane. ⌘-click a sidebar session to open a second session side by side.
- Session model **[V]**: "each conversation is a session: it has its own chat history, project folder, and code changes". Each session gets a worktree under `<project-root>/.claude/worktrees/`; archive icon on hover; "Auto-archive after PR merge or close". "Use the controls at the top of the sidebar to filter sessions by status, project, or environment, and to group sessions by project." Rename by clicking the title in the toolbar. Environments: Local, Cloud, SSH, WSL.
- Attention **[V]**: "The desktop app sends an OS notification when a Code session finishes a task and you aren't currently viewing that session." "Claude Code also sends a desktop notification when CI finishes." Dispatch-spawned sessions "appear in the Code tab's sidebar with a Dispatch badge. You get a push notification on your phone when it finishes or needs your approval." Claude "offers the work as a task chip in the chat" for out-of-scope follow-ups. Cross-session messages render "as a card labeled with the sending session's title and a link back".
- Diff/PR **[V]**: "a diff stats indicator appears showing the number of lines added and removed, such as `+12 -1`. Click this indicator to open the diff viewer, which displays a file list on the left and the changes for each file on the right." Line comments, ⌘⏎ submits all; "Review code" asks Claude to review its own diff and "focuses on high-signal issues"; CI status bar with Auto-fix and Auto-merge (squash; needs `gh`).
- Density/transcript **[V]**: view modes Normal / Verbose / Summary (Ctrl+O); "Use Summary when you're running multiple sessions and want to scan results quickly."
- Permission modes **[V]**: Manual, Accept edits, Plan, Auto (classifier-backed), Bypass permissions; mode remembered per folder.
- Onboarding **[V]**: install → sign in → Code tab (prompts upgrade if unpaid) → choose Local/Cloud/SSH/WSL and folder → choose model → prompt. "Start with a small project you know well."
- Platforms/pricing **[V]**: macOS universal, Windows x64 and ARM64, Linux beta (apt/.deb). "Claude Code requires a Pro, Max, Team, or Enterprise subscription." Cowork "Works with a paid plan"; Cowork built-in browser announced Aug 26 2026.
- Technology **[S]**: Electron, per dbreunig quoting Boris Cherny; Anthropic's docs do not state the framework.
- Screenshots: the docs pages read carry no image markup in the fetched text; the vendor's screenshots were not inspected.

## Cross-cutting observations (for Wanigan)

1. **Shell choice is split, and Electron is not a differentiator either way.** Electron: Claude Desktop [S], Superset [V], Emdash [V], T3 Code [V], Crystal/Nimbalyst [V], Cursor [S]. Tauri: Conductor [S], CodeLayer (old) [S]. Native Rust: Warp [V], Zed [V]. Web: Vibe Kanban, Terragon, Devin, Amp. Nobody markets the framework; performance essays (Conductor rewrite) come from third parties.
2. **The attention vocabulary has converged on three or four states.** Warp: Working / Blocked / Failed / Success with a "Request" notification class [V]. Devin: working / blocked / finished plus "Action Required" and an unread orange dot [V]. Superset: working indicators, completion chime, dock badge for "needs your attention" [V]. Zed and Amp: a single "waiting/ready for you" notification [V]. Claude Desktop notifies on finish and on Dispatch approval [V]. Wanigan's attention surface should map cleanly onto blocked-on-you vs finished vs errored, each with an unread marker that clears on open, since that is what operators now expect.
3. **Status detection is hook-based and honest about coverage.** Superset and Emdash both install lifecycle hooks into each agent's own config and say status "only works for agents launched through" the app [V]. That matches Wanigan's injected runtime configuration; the honest-unsupported stance is already industry practice.
4. **The sidebar row is the unit of scanning.** Every desktop competitor lists sessions/workspaces/threads in a left rail with inline chips: GitHub status (Conductor), running agents and ports (Superset), "running · 4m" (Emdash), Dispatch badge (Claude), source/status/duration/creator (Warp), persistent labels like "PR created" (Devin). Lifecycle shelves — Conductor's backlog/in progress/in review/done, T3 Code's pinned/active/settled/snoozed with auto-settle on PR merge, Nimbalyst's kanban phases — are the next step beyond a flat list.
5. **Diff review is table stakes; line comments sent back to the agent are the norm.** Conductor, Claude Desktop, Factory, Vibe Kanban, Superset and Cursor all describe commenting on a changed line and having the agent act on it [V]. Claude Desktop, Conductor and Devin add self-review or PR/CI status bars. Devin added word-level highlighting and a file-tree Changes tab in summer 2026.
6. **Notification plumbing is layered.** Warp's model is the most complete on paper: toast (max two), mailbox with unread/error filters, tab badge, OS notification [V]. Claude Desktop, Superset, Zed and Amp rely on OS notifications plus a dock badge or sound.
7. **Pricing clusters at $20 / $50 / $100 / $200.** Free tiers exist at Conductor, Superset, Warp, Cursor, Zed, HumanLayer, Emdash/T3 Code/Nimbalyst (open source). No free tier on Amp or Factory pricing pages. Conductor and BridgeMind charge $50 for the orchestrator itself; most others monetise cloud compute or tokens.
8. **The field is consolidating.** Terragon (shut down, Jan/Feb 2026), Vibe Kanban's company (Apr 10 2026), Crystal (Feb 2026) and CodeLayer's original codebase are gone or rebuilt; Conductor raised a Series A (Mar 30 2026); Codex-app docs now live under ChatGPT.
9. **Design writing is thin.** Only Cursor's blog and Anthropic's docs give first-party rationale; Conductor's blog is three posts. Typography and density are almost never discussed publicly; T3 Code documents a 0–400 ms panel-animation slider honouring OS reduced motion, and Conductor documents custom fonts, nine syntax themes and colourblind-safe options.
