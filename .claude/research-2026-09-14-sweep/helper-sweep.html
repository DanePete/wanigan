  1. Show what npm run build actually runs, in the approval

    When a command goes through the gate, expand npm|pnpm|yarn|bun run, make and just targets into the script body from the worktree's current package.json, Makefile or justfile. Flag the script if its entry changed since the launch commit. Add a deterministic line: what the command does, what it touches, whether it can be undone. This matters most on the phone, where there is no terminal to scroll.

    Wanigan todaypolicy.ts matches command strings; nothing reads a manifest's scripts.

    EvidenceIn 409k approve/deny decisions, payloads behind a familiar npm run name were approved 52.5% of the time, against 28.4% for other exfiltration attempts. scalex, 5 Aug · deterministic explainer: codex-approval-explainer

    Checked absentS–M

  2. Auto-mode denials become attention items

    Auto mode has been the default for Pro, Max and Team since 14 August, so sessions now hit a second gate Wanigan cannot see. The PermissionDenied hook carries denial_reason and can answer retry: true. Surface each denial with its matched rule and three actions: allow a retry, add an allow rule, or leave it. Then compile each trust level into autoMode rules passed through --settings. The classifier reads that flag and deliberately ignores a repository's own settings.

    Wanigan todayhooks.ts okOf() counts PermissionDenied as a failed step on the Timeline, with no reason and no attention item.

    EvidenceAt Gusto, about 10% of transcripts since mid-May contained an auto-mode denial. auto-mode-config docs · Running auto mode in production, 7 Aug

    Checked absentS–M

  3. "Needs review" as a state, with a mark on each reviewed file

    A session that finished with a non-empty diff and no review mark is its own bucket, separate from idle. Inside it, each changed file gets approve, reject or comment. That state persists in SQLite and survives reopening. Submit sends one message into the session through the existing review-notes path. Sort the bucket by diff size.

    Wanigan todayAttention states are permission, error, finished, idle, working and stalled. Review notes anchor to lines, and no file carries a reviewed state.

    EvidenceSuperset "Needs review", 16 Aug · Antigravity artifact review, CLI 1.1.14 · Agentastic guided review, 6 Sep

    Builds on review notesM

  4. "Since you last looked", built from evidence

    When a tab regains focus, show what happened since it lost focus: turns, files changed, commands that failed, cost and current state. It is built from the hook timeline and checkpoints, with no model call. If Claude Code's own recap (one line, at most 400 characters) is persisted somewhere readable, show it beside that summary and label it as the harness's words.

    Wanigan todayNo recap of any kind (recap appears only in a handover test).

    EvidenceJean session recap · Claude Code session recap · Codex recap schema, #45090

    Probe the Claude recapS

  5. Separate what the agent's edit tools changed from everything else

    Offer three scopes in the diff: files an edit tool touched this session, all uncommitted changes, and the whole branch. A file that changed without an edit tool touching it is labelled "changed outside edit tools". That covers sed -i, Python heredocs, formatters and the operator. Turn on bashEditDiffEnabled (2.1.269) in injected settings so Bash results carry their own diffs. The same split lets a commit stage only the hunks the session wrote.

    Wanigan todayPer-turn checkpoints capture the whole tree, and nothing attributes a change to a tool.

    EvidenceAntigravity change scopes, 24 Aug · Nimbalyst session-hunk staging, 0.75.2 · heredoc edits in Armin Ronacher, 7 Sep

    Checked absentM

  6. A usage-limit wait is named, not called stalled

    Since 2.1.234, a subscription session that hits its limit waits in place and continues at reset, and that is on by default. Give it a reason code with the reset time, suppress stall alerts during the wait, and notify when it resumes. For a session that already exited, offer an explicit "resume at reset" that shows the time and can be cancelled. It is never on by default.

    Wanigan todayLimits and burn rate are read per account, and the attention queue has no wait state, so a waiting session reads as stalled after 10 minutes.

    EvidenceWait for a usage limit to reset · Desktop auto-continue, W33 · claude-powernap

    Probe how the wait showsS

  7. Meter Codex's instruction budget before the learning engine writes

    Codex joins AGENTS.md files from the repository root down and stops at 32 KiB (project_doc_max_bytes). It lists skills within 2% of the context window and shortens their descriptions past that. Root files come first, so the most specific rules are the first to fall off, silently. Wanigan projects into nested AGENTS.md and .agents/skills, so it can cut off the very rule it just added. Check before applying a projection and in the Context view. While doing so, flag paths and commands in instruction files that no longer exist.

    Wanigan todaycontext/instructions.ts checks only whether Claude reads AGENTS.md. Nothing models Codex's loader or its byte limit.

    EvidenceCodex config reference · Rethinking skills and prompts for GPT-6 Astra, 11 Sep · agents-doctor · agents-md-lint

    Checked absentS

  8. Spend yield: shipped, reverted or abandoned

    Class each session's cost by what happened to its work: merged, merged then reverted, or discarded. Show cost per merged commit per project and model. Heuristic tools match commits by timestamp; Wanigan can use exact merge and discard records once it stores them. Setting OTEL_METRICS_INCLUDE_REPOSITORY (2.1.269) at launch puts vcs.* attributes on cost metrics, so the join comes from the data rather than the working directory.

    Wanigan todayThe worktrees table stores removed_at only. Whether the work was merged or discarded is not recorded, so this needs an additive column first.

    EvidenceCodeBurn yield · a 35-hour unattended run: about $1,200 for 79 commits, Armin Ronacher

    Checked absentS–M

  9. New dependencies are review items

    For each checkpoint, read manifest and lockfile changes and list every added or upgraded package with its version, and whether an install ran in the session. An optional advisory lookup (OSV, GitHub Advisory) goes in the egress report as disclosed traffic. It must say "unknown" rather than "safe" when no source covers the ecosystem, and flag versions published in the last 72 hours.

    Wanigan todayDiffs show manifest changes as text; nothing lists dependencies as decisions.

    EvidenceAcross 16,893 sessions, the three agents chose the same tool only 42% of the time, and Claude Code searched the web in about 30% of cases. Armature, 3 Sep · deptrust

For Codex, list background terminals through app-server thread/backgroundTerminals/*. Otherwise Halt can report success while a dev server keeps running.

    Snooze a session for a set time, waking early if it raises an attention event. Mark a session unread after looking. Add a chord for the next session that needs you and one to reopen the last closed tab. On an exited tab, put a Resume button that says plainly it starts a new process.

    Wanigan todayUnread badges and positional ⌥⌘←/→. Snooze exists only in the learning inbox. An exited session says "Resume it from Recent".

    When a session reports StopFailure, errors or stalls, check status.claude.com/api/v2/incidents.json (and OpenAI's status page for Codex). If an incident is open on a matching component, tag the attention item "provider incident" with its name. That stops the operator debugging a repository that isn't broken. It is a public GET with no user data, listed in the egress report.

    Wanigan todayNo status-page read; a provider error looks like any other error.

Corrections

Places where a research pass said something the code or a primary source does not support.

"Wanigan can compute spend yield exactly"
Not yet. worktrees keeps path, repo_root, branch, session_id, created_at, removed_at. Whether a removal was a merge or a discard is not persisted, so an additive column comes first.
"Compressed Codex rollouts read as zero usage"
A future risk, not a live bug. PR #42039 writes .jsonl.zst, and codex-sessions.ts would skip those files. But installed Codex 0.154 lists local_thread_store_compression as "under development, false".
"Guard model switches with PreModelSwitch"
This reverses a recorded decision. hooks.ts:218 asks only for PostModelSwitch, because a recorder that can block can wedge a session when the listener is busy. A warning built on the Post event is still open.
"Wrap PR comments in an untrusted envelope"
Mostly done in flight: pr-feedback.ts says the text is quoted and asks for it to be read as information. What is left: a comment body must not be able to forge that header.
"Keep-awake silently fails with the lid closed"
It doesn't claim to work. Settings says a closed lid sleeps the Mac unless an external display holds it. Staying awake with the lid closed is a real gap, but it needs a privileged helper, which is a trust-boundary decision.
"Lint policy rules that match nothing"
Premature. Antigravity's bug was a user rule that parsed to empty and matched everything. Wanigan's rules are built-in today; this becomes a gate once operators can write rules.
rtk, the most-starred helper (80k)
Two passes disagreed on it. It is left out as a default: it rewrites git status to rtk git status, so the transcript no longer shows the command that ran. Acceptable only as a declared per-session opt-in measured in a paired trial.
"GPT-6 Astra" looked like an SEO invention
It is real: it appears in openai/codex releases 0.153.1–0.154.0, OpenAI's API model page and the system card. Several other SEO-site claims were not used.

Probe before building

Undocumented, or documented for a different surface.

  • Usage-limit wait. How a waiting Claude session shows it: PTY text, a transcript entry, or a hook.
  • Claude's session recap. Whether the recap line is persisted anywhere Wanigan can read without triggering /recap.
  • Codex daemon. Whether a PTY-launched Codex TUI on macOS attaches to the shared app-server daemon, which decides whether Halt misses work.

Left out on purpose

Seen in the sweep and ruled out by Wanigan's five values.

  • Cloud execution. Conductor Cloud and routines, Codex Agents API, Warp Factories, Ramp Inspect.
  • Hosted relays. Happy's relay, Superset Pages, Antigravity's Remote Control hub, chat bridges.
  • Merging without a person. Claude Desktop auto-merge, self-landing merge queues, megabatch pitches.
  • Hidden routing or fan-out. claude-code-router, better-ccflare, /boost. Codex Ultra delegates automatically, so label it where offered.
  • Changing what the agent sees without saying so. rtk as a default, pxpipe's image-compressed context, ccxray's stats footer.
  • Installers that write into repositories. Graft, shift-log, chat-history's quiet skill install.
  • Spend nobody asked for. Prompt Improver on every message, automatic credit overages.
  • Composite grades. CodeBurn A–F, Node9's score. Keep their findings, drop the grade.
